# DogForst-Paint
DOGFORST Paint Studio — авторский графический редактор для Windows. Рисование, работа со слоями, текстом, фигурами и обработка изображений. Проект активно развивается: новые функции, улучшения и исправления выходят регулярно.
# 📥 Установка DOGFORST Paint Studio

Из-за большого размера приложения мы решили распространять DOGFORST Paint Studio не в виде отдельного EXE-файла, а через установочный пакет.

Установка несложная и займёт всего несколько минут.

 1. Скачивание
- Скачайте установочный архив целиком.
- Дождитесь завершения загрузки.

 2. Подготовка файлов
- Найдите скачанный архив.
- Распакуйте его в удобное место на компьютере.
- Откройте полученную папку.

**Важно:** не запускайте установку прямо из архива. Сначала необходимо распаковать все файлы.

 3. Установка программы
- Найдите файл `Setup.exe`.
- Запустите его двойным нажатием мыши.
- Следуйте инструкциям установщика.
- Дождитесь окончания установки.
- Если Windows запросит разрешение на установку, подтвердите действие, предварительно убедившись, что файл получен из официального источника проекта.

 4. Запуск DOGFORST Paint Studio
После завершения установки:
- Нажмите кнопку `Start` / `Запустить`, если она появится.
- Либо найдите DOGFORST Paint Studio через меню «Пуск».
- Также можно воспользоваться ярлыком на рабочем столе, если он был создан.

Готово! Теперь можно пользоваться DOGFORST Paint Studio. 🎨

 ⚠️ Если возникли проблемы
- Не удаляйте файлы программы во время установки.
- Не перемещайте отдельные компоненты приложения после установки.
- Убедитесь, что архив распакован полностью.
- Если программа не запускается, попробуйте переустановить её.

**Спасибо, что выбираете DOGFORST Paint Studio!**
